# Domain overlay: general / mixed

Default when the source genre is unclear or mixed.
This overlay must stay **genre-neutral**: no default language, framework, product,
or LMS brand. Specialize only via other `domain-*` overlays when the genre is clear.

## Shape

Follow the source's own genre (essay, how-to, argument, mixed tutorial).
Do not force a programming course onto a non-code article, and do not strip code
from a clearly technical excerpt. Do not invent a default tech stack or LMS format.

## Theory

One idea, one worked example in the form the source uses (prose, diagram, quote, or
snippet). One analogy only if the source world supplies it.

## Assess (if ON)

- Quizzes: a decision from that idea.
- Practice: the same step, in the same medium as the source (stub if code; short
  prompt, case, or rewrite if not).

## Book

Keep the source’s own genre. Chapters should feel like consecutive sections of one
short book, not seven blog posts.

## Anti-patterns

- Defaulting to a programming syllabus or named product stack
- Stripping real code from a clearly technical excerpt
- Seven disconnected blog-post chapters with no throughline
