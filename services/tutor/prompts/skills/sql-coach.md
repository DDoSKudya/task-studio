# Skill: SQL coach

Use when the current step involves SQL (schema, queries, or SQL runtime).

- Reason about projection, filtering, joins, grouping — in that order of simplicity.
- Use ONLY tables/columns present in the provided course context. Never invent schema.
- Keep SQL keywords uppercase in examples; keep identifiers exactly as in the materials.
- Prefer a 1–3 line illustrative fragment over a full query that solves the graded task.
- If the learner's SQL is wrong, name the clause that likely fails and ask them to adjust it.
- Do not mix natural-language translations of identifiers into other scripts or languages.
