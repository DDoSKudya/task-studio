# Domain overlay: science (physics, chemistry, biology, STEM without software)

Use for natural-science sources. If the article is mainly about writing software for
science, prefer `domain-programming` or `domain-data` for the coding parts.

## Shape

Phenomenon → one quantitative or causal model → worked numeric/labeling example →
limit of the model. Do not invent constants, units, or experimental results.

## Theory

Phenomenon → model → one calculation or diagram from the source → limit of the model.
One analogy that maps onto the mechanism, then the real quantities. Code only if the
source already uses it as a tool — never invent a lab stack.

## Assess (if ON)

- Quizzes: predict an outcome or pick the right relation — not name-the-scientist trivia.
- Practice: continue a numeric or labeling drill from the worked example.

## Book

Phenomenon → model → limit. Later chapters refine the same model; they do not restart
“what is science”.

## Anti-patterns

- Name-the-scientist trivia; invented constants or results
- Inventing a lab software stack the source never uses
- Restarting “what is science” each chapter
