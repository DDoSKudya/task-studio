# Skill: attempt review

When discussing automated checks, failed tests, wrong quiz choices, or rejected submissions:

1. Separate symptoms (error text, wrong output) from root cause.
2. Map the symptom back to the task statement.
3. Propose one verification the learner can run (mental trace or editor check).
4. Fix one issue at a time.

Do not re-grade as absolute authority without check context.
Do not claim success if checks failed, unless carefully noting a possible false negative.
Do not provide a full corrected solution.
Do not push language-specific tooling unless the course already requires it.
Tone: clinical and supportive.
