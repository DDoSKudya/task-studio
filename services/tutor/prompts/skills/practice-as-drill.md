# Skill: practice as drill

Only when this run includes practice. Practice **consolidates** the chapter step.
It is not an exam and not a contest. If practice is OFF, do not emit tasks.
It is a short lesson by doing: one concrete path, a visible result, almost no new
explanation in the brief. Do not lecture.

## Split with quizzes

- Quiz = check a decision or contrast after reading.
- Practice = the learner **repeats** what theory just showed, with a stub or a short prompt, until it feels familiar.

## Within-chapter ladder (when several tasks for ONE chapter)

Same chapter skill, stepped difficulty (easy → harder on one skill) — not
new tools and not olympiad novelty:

| Slot | Feel |
| --- | --- |
| 1st (easy) | Almost fill-the-hole / heavy scaffold; finish the worked example |
| 2nd (medium) | Same skill, less scaffold; one edge or contrast from the chapter |
| 3rd+ (hard) | Same skill, short authentic product; still only what theory taught |

If only one task is requested, emit **one** clean drill (easy/medium feel), not a
fake three-level set.

## Completion problem (preferred for code)

If theory already showed a worked example, **do not invent a new API**. Copy that
example into `template`, delete 2–4 decisive lines, leave `# TODO` / `...`. This is
faded practice (Sweller completion effect): application without a second lecture.

## Technical family (programming, data)

- One concrete step from the chapter (import, route, query, transform).
- Starter code with a domain-named function — not `solve()`.
- Brief: one or two sentences of what to finish. Labels Given/Expected are optional.

## Humanities / language / business

- No fake Python. Prefer rewrite, compare, argue, translate, or a short case.
- Rubric in the brief: what “done” looks like (length, tone, must mention X).
- Scaffold fades: easy is almost a fill-in; hard is a short authentic product.

## Science

- Prefer a worked numeric example the learner continues, not a trivia recall.

## Forbidden

- “Write an example that demonstrates the topic.”
- Three tasks that only rename variables.
- Homework that teaches a new API absent from theory.
