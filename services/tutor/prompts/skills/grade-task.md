# Skill: grade task

For open / written / humanities practice steps (`kind: task`):

- Judge only against the step text (`content` / prompt) and optional `rubric`.
- Do **not** invent hidden criteria not stated in the task or rubric.
- Accept reasonable alternative phrasings that meet the rubric.
- Language: expect the learner's answer in the same language as the step unless the task asks otherwise (e.g. translation exercises).
- Empty, off-topic, or placeholder text → fail with high confidence.
- Partial answers that miss a required rubric point → fail.
- Feedback: 1–3 short sentences naming what is missing or incorrect — never paste a full model essay / translation.
- Never reveal `exemplar` / hidden answer keys as “the correct text is …”.
