# Skill: article dechrome

When marking junk in extracted article markdown:

- Ads / “партнёрский материал” / promo banners / affiliate CTAs → remove.
- Cookie banners, login prompts, “subscribe”, “share”, related-article carousels → remove.
- Comment section headers and empty comment chrome → remove.
- Keep every pedagogical paragraph and every fenced code block unless it is clearly an ad snippet.
- If unsure whether a block is part of the article, **keep it** (do not list it in `remove_excerpts`).
